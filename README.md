# homebrew-tap

[![Test](https://github.com/albertovincenzi/homebrew-tap/actions/workflows/test.yml/badge.svg)](https://github.com/albertovincenzi/homebrew-tap/actions/workflows/test.yml)

Homebrew formulae of [albertovincenzi](https://github.com/albertovincenzi), for macOS and Linux.

```sh
brew install albertovincenzi/tap/git-lopper
```

| Formula | Description |
| --- | --- |
| [git-lopper](https://github.com/albertovincenzi/git-lopper) | Find stale git worktrees in all your repositories and remove them safely |

The release workflow of each project writes its formula here. CI installs and tests each
formula on Linux and macOS, on Intel and Arm.
